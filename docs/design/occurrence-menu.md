# Occurrence menu

To a manager, on a free occurrence:

```
┌ Thu 29 Oct · 10–13 ──────────────────────── ✕ ┐
│ [Sign up]                                     │
│                                               │
│ Chloé (1)                                     │
│ Bruno (2)  📝                                 │
│ David (0)                                     │
│ Emma (1)  ⛔                                  │
│                                               │
│ Absent Mon 26 Oct 2026 – Sun 1 Nov 2026       │
└───────────────────────────────────────────────┘
```

Chloé and Bruno are green (Preferred), David has no colour (none
stated), Emma is grey (absent); the text under the names is the icon
clicked.

To a volunteer, on a free occurrence:

```
┌ Thu 29 Oct · 10–13 ──────────────────────── ✕ ┐
│ [Sign up]                                     │
└───────────────────────────────────────────────┘
```

On the user's proposed registration:

```
┌ Sat 31 Oct · 10–13 ──────────────────────── ✕ ┐
│ [Confirm]                                     │
│ Cancel registration…                          │
└───────────────────────────────────────────────┘
```

On a confirmed registration, Cancel registration… clicked:

```
┌ Thu 5 Nov · 10–13 ───────────────────────── ✕ ┐
│ Cancel this registration?                     │
│ [Yes, cancel]  Keep it                        │
└───────────────────────────────────────────────┘
```

Refused:

```
┌ Thu 29 Oct · 10–13 ──────────────────────── ✕ ┐
│ Someone took this slot in the meantime.       │
└───────────────────────────────────────────────┘
```

To a volunteer, on another member's registration:

```
┌ Thu 5 Nov · 10–13 ───────────────────────── ✕ ┐
└───────────────────────────────────────────────┘
```

On an obsolete registration:

```
┌ Thu 12 Nov · 10–13 ──────────────────────── ✕ ┐
│ Cancel registration…                          │
└───────────────────────────────────────────────┘
```
