# Create an account

```
(logo)                                     [English ▾]

Create an account
  Display name  [                ]
  Email         [                ]
  Password      [                ]
  [Create account]

Already have an account? Sign in
```

After [Create account]:

```
(logo)                                     [English ▾]

Check alice@example.org for a confirmation link.
Resend the email

Email sent.
```

Refused, under the form:

```
  [Create account]
  An account already exists for this email. Sign in instead.
```

The other messages take the same place: "This email has not been
invited. Ask a manager of your association to add you as a member.",
"We couldn't send the confirmation email. Try again later.",
"Something went wrong. Try again."
